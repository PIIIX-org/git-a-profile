# Runs

Every forge leaves a record here: `runs/<slug>/REPORT.md`, copied from
`_template/` and filled in during Loop 4. The slug is the subject (`octocat`,
`acme-org`, `owner-repo`).

The run log is how the pipeline proves it works, and how the next person learns
from the last. A run isn't done until its report is committed and the live profile
is confirmed by screenshot.
